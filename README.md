# Викторина — мини-приложение для Max

Мини-приложение для мессенджера [Max](https://max.ru) с реалтайм-викторинами: одиночная игра, игра против бота и мультиплеер с друзьями по коду комнаты.

Работает на [ru.ozfi.store](https://ru.ozfi.store), открывается через бота в Max.

## Возможности

- **Три режима игры**: одиночная, против бота, мультиплеер по коду комнаты (2+ игроков)
- **Категории и подтемы** — паки вопросов группируются по папкам (например «Медицина» → «Лечебное дело», «Военная медицина» и т.д.), можно играть по всему разделу сразу или по одной теме, вопросы выбираются случайно
- **Настраиваемое количество вопросов** — от 1 до размера выбранного пула, автоматически ограничивается сервером
- **Вопросы с медиа** — картинка и/или аудио у вопроса, а также картинка у отдельных вариантов ответа
- **Защита от читерства**: короткий таймер на ответ, у каждого игрока свой случайный порядок вариантов, детект переключения вкладки/потери фокуса, флаг подозрительно быстрых ответов, «sudden death» — если один игрок в мультиплеере уже ответил, у остальных остаётся не больше 5 секунд
- **Авторизация только через Max** — сервер проверяет криптографическую подпись `initData` (HMAC-SHA256 по схеме Telegram Mini Apps), играть напрямую в браузере нельзя
- **Профили и рейтинг** — ELO-рейтинг считается только для будущего режима подбора соперника (matchmaking), не для обычных игр с друзьями/ботом
- **Реконнект** — если игрок случайно закрыл приложение или потерял связь, у него есть 45 секунд на переподключение с восстановлением текущего вопроса и оставшегося времени
- **Админ-панель** — список игроков с рейтингом, бан/разбан (доступна по ID из `ADMIN_USER_IDS`)
- **Приглашение через Max** — шеринг кода комнаты через нативное окно Max, копирование кода в буфер

## Технологии

- **Backend**: Node.js (без фреймворков), нативный HTTP-сервер + [`ws`](https://github.com/websockets/ws) для WebSocket
- **Frontend**: чистые HTML/CSS/JS, без сборки и зависимостей
- **Хранилище**: вопросы — JSON-файлы на диске, профили игроков — `data/users.json` (не в git)

Сервер специально сделан лёгким — рассчитан на слабый VDS (1 ГБ RAM), потребляет ~17 МБ памяти в простое.

## Структура проекта

```
server/
  index.js     — HTTP-сервер, WebSocket-роутинг, паки вопросов, matchmaking-заготовка
  rooms.js     — игровая логика комнат (вопросы, таймеры, подсчёт очков, анти-чит)
  auth.js      — проверка подписи initData от Max
  store.js     — хранилище профилей игроков (рейтинг, баны)
  env.js       — загрузка .env (токен бота, админы)
public/
  index.html, style.css, app.js — клиент мини-приложения
  media/       — картинки/аудио для вопросов
questions/
  *.json                — паки вопросов верхнего уровня
  <категория>/*.json     — паки, сгруппированные по теме
  README.md              — как добавлять новые паки (шаблон, формат медиа)
```

## Как добавить вопросы

Смотрите [questions/README.md](questions/README.md) — там подробный шаблон на русском: какие поля обязательны, как подключать картинки/аудио, как группировать паки по темам.

## Локальный запуск

```bash
cd server
npm install
PORT=3000 node index.js
```

Понадобится файл `.env` в корне проекта:

```
BOT_TOKEN=токен_бота_в_max
ADMIN_USER_IDS=123456789,987654321
```

Без реального `BOT_TOKEN` проверка подписи `initData` не пройдёт, и играть можно будет только внутри настоящего Max-клиента с валидной подписью.

## Деплой

Разворачивается на VDS через systemd-сервис (`quiz-app.service`) за nginx-прокси с SSL. Домен и HTTPS настроены отдельно от репозитория.
