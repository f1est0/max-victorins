# Как добавить новый набор вопросов

## Коротко

1. Создайте файл `questions/<название>.json` (например `questions/medicine.json`) — скопируйте шаблон ниже.
2. Если в вопросах есть картинки/аудио — положите файлы в `public/media/<название>/`.
3. Заполните вопросы. Пак и счётчик количества вопросов появятся в приложении **автоматически** — ничего больше нигде прописывать не нужно, количество вопросов на экране берётся прямо из файла.

## Шаблон файла (`questions/medicine.json`)

```json
{
  "title": "Вопросы по медицине",
  "questions": [
    {
      "text": "Сколько камер в сердце человека?",
      "options": ["2", "3", "4", "5"],
      "correctIndex": 2
    },
    {
      "text": "Что изображено на картинке?",
      "image": "medicine/xray.jpg",
      "options": ["Лёгкие", "Печень", "Почки", "Сердце"],
      "correctIndex": 0
    },
    {
      "text": "Какой орган издаёт этот звук?",
      "audio": "medicine/heartbeat.mp3",
      "options": ["Сердце", "Желудок", "Лёгкие", "Кишечник"],
      "correctIndex": 0
    },
    {
      "text": "Выберите правильную картинку",
      "options": [
        { "text": "Вариант A", "image": "medicine/opt-a.jpg" },
        { "text": "Вариант B", "image": "medicine/opt-b.jpg" }
      ],
      "correctIndex": 1
    }
  ]
}
```

## Поля вопроса — что куда писать

| Поле | Обязательно? | Что это |
|---|---|---|
| `title` (в начале файла) | да | Название набора — то, что видит игрок в списке паков |
| `questions` | да | Список вопросов (массив) |
| `text` | да | Текст вопроса |
| `options` | да | Ровно 4 варианта ответа. Каждый вариант — либо просто текст в кавычках (`"Париж"`), либо объект `{ "text": "...", "image": "..." }`, если у варианта есть картинка |
| `correctIndex` | да | Номер правильного варианта, **считая с нуля**: `0` — первый вариант, `1` — второй, `2` — третий, `3` — четвёртый |
| `image` | нет | Путь к картинке вопроса (см. ниже) |
| `audio` | нет | Путь к аудио вопроса (см. ниже) |

Картинку и аудио можно указать **одновременно у самого вопроса**, а также **отдельно у каждого варианта ответа** (для вопросов вроде «угадай по фото»).

## Куда класть картинки и аудио

Файлы лежат на сервере в папке `public/media/`. Заведите там подпапку с именем набора, например:

```
public/media/medicine/xray.jpg
public/media/medicine/heartbeat.mp3
```

А в JSON указываете путь **без** `public/media/` в начале — то есть просто `"medicine/xray.jpg"`.

**Форматы:**
- Картинки: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`
- Аудио: `.mp3`, `.ogg`, `.wav`, `.m4a`

**Важно про размер:** сервер небольшой (слабый VDS), поэтому картинки старайтесь сжимать до разумного размера (до ~300–500 КБ каждая), а видео пока не используем вообще — только картинки и звук.

## Как это попадает на сайт

Просто пришлите мне готовый JSON-файл и файлы картинок/аудио — я залью их в `questions/` и `public/media/` на сервере и перезапущу сервис. Через минуту новый набор появится в списке при создании игры.
